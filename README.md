📝 Task Management System
A full-featured task management web application built with the MERN stack (MongoDB, Express.js, React.js, and Node.js). This system is designed to help teams organize, assign, and track tasks efficiently in real-time.

🚀 Features
✅ Task Assignment – Assign tasks to specific users.

⏱ Deadline Tracking – Set and track deadlines with reminders/notifications.

🎯 Priority Levels – Color-coded tags for Low, Medium, and High priority tasks.

📊 Progress Reporting – Track task progress with visual indicators.

🔐 Role-Based Permissions – Admins, Managers, and Users with different access levels.

💬 Real-Time Collaboration – Live updates and collaboration across the platform.

🔐 Secure Authentication – JWT-based login & registration system with protected routes.

🔽 User Dropdown – Easily assign users via dropdown in the task creation form.

📂 Folder Structure
/frontend → React frontend
├── /public              → Static assets
├── /src
│   ├── /components      → Reusable UI components
│   ├── /pages           → Route-specific pages
│   ├── /services        → API service calls
│   ├── /context         → React context for global state
│   ├── /utils           → Utility functions
│   └── App.js           → Main App component

/backend → Node.js backend
├── /config              → Database and JWT config
├── /controllers         → Route handlers
├── /models              → Mongoose schemas
├── /routes              → API routes
├── /middleware          → Authentication & error handling
├── /utils               → Helper functions
└── server.js            → Entry point

📦 Installation
1. Clone the repository
      git clone https://github.com/swatipandey108/Task-Management--ZIDIO.git
      cd Task-Management--ZIDIO
2.Setup backend
      cd backend
      npm install
      nodemon app.js
3.Setup frontend
      cd frontend
      npm install
      npm start
